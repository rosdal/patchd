# Patchd IR: instruction reference

Every instruction of the [Patchd IR](ir.md), what it means, how it prints, what its arguments and `Aux` hold, and whether it can throw. The table in `engine/ir/ops.go` (`opTable`) is the source of truth for the last column; `TestOps` checks every op has an entry there and a printer case.

Conventions:

- `vN` is a value, `bN` a block. Arguments are `Func.Args(instr)`, in order. `Aux.Name` is an interned string, `Aux.Flags` op-specific flags (`AuxFlags`), `Aux.Func` a function ID, and `Func.Parts(instr)` an op-specific part list.
- A value that is not an instruction result prints by kind: `undefined`, `global name` (a module-level binding, import or undeclared global), `%jsx` / `%import` / `%Fragment` / `%import.meta` (intrinsics).
- **Can throw** means the instruction ends its block inside a `try`, with an exceptional edge to the handler (see [exceptions](ir.md#exceptions)).

## Values

| Op         | Printed                                    | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Can throw |
| ---------- | ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `const`    | `v1 = const "abc"`                         | A literal. `Aux.Flags & AuxLitMask` is its kind: `LitString` (cooked text in `Name`, printed quoted), `LitNumber` and `LitBigInt` (as written), `LitBool`, `LitNull`, `LitUndefined` (the identifier `undefined`), `LitRegex` (the whole literal, `/ab+c/gi`, kept for ReDoS rules), `LitStrings` (the strings array of a tagged template; the strings are `PartString` parts: `const strings ["SELECT ", ""]`).                                                 | No        |
| `assign`   | `v2 = v1`                                  | A copy. SSA removes most copies; the builder emits one only where it helps traces: when a value that already has a source name (a parameter, `this`, another variable) is given a second name (`const self = this`).                                                                                                                                                                                                                                             | No        |
| `binop`    | `v3 = binop + v1 v2`                       | A binary operator in `Name`: arithmetic (`+ - * / % **`), comparison (`< <= > >= == != === !==`), bitwise (`& \| ^ << >> >>>`), `in`, `instanceof`. Compound assignments (`+=`) become a `binop` and a write; `&&`, `\|\|`, `??` and their assignments are control flow, never a `binop`. The builder also emits `binop == v undefined` for every `?.` link and `??` (loose equality covers null and undefined), and `binop === v undefined` for default values. | Yes       |
| `unop`     | `v4 = unop typeof v1`                      | `!`, `-`, `+`, `~`, `typeof`, `void` in `Name`. `++`/`--` are a `binop` with `const 1` and a write; `delete` is its own op.                                                                                                                                                                                                                                                                                                                                      | No        |
| `template` | `v5 = template ["SELECT ", v1, " FROM t"]` | A template literal with its static parts kept apart from its expressions: the parts are `PartString`, one more than the arguments, interleaved (empty strings are not printed). Vital for injection rules: the SQL text is in the parts, the tainted values are the arguments. A template without substitutions is a `const`.                                                                                                                                    | Yes       |
| `phi`      | `v15 = phi [b1: v1, b2: v2]`               | SSA merge: one argument per predecessor of the block, in `Block.Preds` order (exceptional predecessors included). Phis come first in their block. Operands from dead code are the phi itself and mean "no value".                                                                                                                                                                                                                                                | No        |
| `catchval` | `v16 = catchval`                           | The caught exception, first instruction of a `catch` or `finally.throw` block.                                                                                                                                                                                                                                                                                                                                                                                   | No        |
| `unknown`  | `v17 = unknown WithStatement [v1]`         | Syntax not lowered: `Name` is its compiler kind. Analyses treat the result as anything and the instruction as having any effect. Arguments, when present, are values the syntax uses (the object of a `with`). Counted by the coverage report.                                                                                                                                                                                                                   | Yes       |

## Memory

`load`, `store` and `delete` share one addressing scheme, chosen by `Aux.Flags`:

| Form                 | Flags          | Arguments        | Meaning                                                                                                                                               |
| -------------------- | -------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| `v1.name`            | none           | object           | property with a static name in `Name`; also `o["literal"]` and `o[0]` (printed `v1["odd-key"]`, `v1[0]`); private names keep their `#` (`v1.#secret`) |
| `v1[v2]`             | `AuxDynamic`   | object, key      | element with a computed key                                                                                                                           |
| `global name`        | `AuxGlobal`    | the global value | a module-level variable, import binding or undeclared global by `Name`                                                                                |
| `*v1`                | `AuxCell`      | cell             | the variable a cell holds (captured variables; see `cell`)                                                                                            |
| `super.name this=v1` | `AuxSuper`     | `this`           | a property of the home object's prototype, read with `this` as receiver                                                                               |
| `v1[of]`             | `AuxIterValue` | iterated value   | the next element of a `for…of` (awaited separately for `for await`)                                                                                   |
| `v1[in]`             | `AuxIterKey`   | object           | the next key of a `for…in` (prototype-pollution rules care)                                                                                           |
| `v1[2:]`             | `AuxRest`      | iterated value   | the rest of an array pattern from index `Name` on                                                                                                     |

| Op       | Printed               | Meaning                                                                                                                                                                                                                                                                                                                                                                             | Can throw |
| -------- | --------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `load`   | `v6 = load v1.name`   | Reads a place.                                                                                                                                                                                                                                                                                                                                                                      | Yes       |
| `store`  | `store v1.name = v2`  | Writes a place; the value is the last argument. Class definitions store their members with `AuxMethod`, `AuxGetter`, `AuxSetter` and `AuxStatic` (printed after the line: `; method`, `; get static`), and `extends` with `AuxProto` (`store v6.__proto__ = v5 ; proto`). CommonJS `module.exports = …` and `exports.x = …` are ordinary stores, also recorded in `Module.Exports`. | Yes       |
| `delete` | `v7 = delete v1.name` | The `delete` operator on a property or element; the result is the boolean. `delete x` on anything else is the operand's value and `const true`.                                                                                                                                                                                                                                     | Yes       |
| `cell`   | `v8 = cell n`         | Allocates a fresh cell for captured variable `Name`. Emitted where the binding comes into existence: function entry (parameters, `var`), block entry (`let`, `const`, `class`, function declarations), each iteration of a `for (let …)` loop (copied from the previous iteration's cell, before the update), each iteration of a `for…of`/`for…in` body.                           | No        |

## Calls and construction

`call` has five shapes, chosen by `Aux.Flags`:

| Printed                     | Flags                   | Arguments                                                                                                                                                                         |
| --------------------------- | ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `call v1(v2, v3)`           | none                    | callee, arguments                                                                                                                                                                 |
| `call v1.query(v2) this=v1` | `AuxMethod`             | receiver, arguments; `Name` is the method. A method call keeps its shape (no separate `load` of the method) so models match on receiver type plus name. `o["m"]()` is static too. |
| `call v1[v2](v3) this=v1`   | `AuxMethod\|AuxDynamic` | receiver, key, arguments                                                                                                                                                          |
| `call super.m(v2) this=v1`  | `AuxMethod\|AuxSuper`   | `this`, arguments                                                                                                                                                                 |
| `call super(v2) this=v1`    | `AuxSuperCall`          | `this`, arguments: `super(…)` in a derived constructor                                                                                                                            |
| `call v1(v2) this=v3`       | `AuxWithThis`           | callee, `this`, arguments: a call with an explicit receiver, used for `o.m?.()` (the method is loaded to check it) and for running `ClassInit`/`StaticInit`                       |

Other call flags, printed at the end of the line: `AuxOptional` (written with `?.`; the short-circuit itself is control flow), `AuxTagged` (a tagged template: the first argument after the callee is the strings `const`, then the values), `AuxJSX` (`call %jsx(tag, props, children)`; `Name` is the tag as written), `AuxDecorator` (applies a decorator, see below), `AuxRequire` (`require("x")` with a literal; also recorded in `Module.Imports`), `AuxImport` (`call %import(v1)` for dynamic `import()`), `AuxEval` (direct `eval`, warning `IR004`), `AuxIIFE` (the callee is a function expression written in place). For a plain call `Name` holds the callee's identifier, when it is one. `fn.call`, `fn.apply`, `fn.bind`, promise methods (`then`, `catch`, `finally`, `Promise.all`) are ordinary method calls; v0.5's models interpret them.

Decorators: `@Body() dto` lowers to the decorator expression (`v5 = call v4()` for `Body()`), then `v7 = call v5(v3) ; decorator @Body param create#0`, where the argument is the target (the prototype, or the constructor for static members, constructor parameters and the class) and the part (`PartTarget`) says what is decorated: `class`, `method m`, `get x`, `set x`, `field x`, `param m#i`. Applied in TypeScript's order: each member in source order (its parameters' decorators, then its own), the constructor's parameters, then the class; several decorators on one target are evaluated in source order and applied last to first. A class decorator's return value does not replace the class binding.

| Op     | Printed                          | Meaning                                                                                                   | Can throw |
| ------ | -------------------------------- | --------------------------------------------------------------------------------------------------------- | --------- |
| `call` | `v7 = call v6.query(v5) this=v6` | A call; shapes above.                                                                                     | Yes       |
| `new`  | `v8 = new v1(v2)`                | A constructor call: callee, arguments. `Name` holds the callee as written (`URL`, `Prisma.PrismaClient`). | Yes       |

## Literals

| Op       | Printed                                | Meaning                                                                                                                                                                                                                                                                                                                                                                                                                                                                                            | Can throw |
| -------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `object` | `v9 = object {a: v1, [v2]: v3, ...v4}` | An object literal. Each part consumes arguments: `PartKey` (`a: v1`, one), `PartComputed` (`[k]: v`, two: key then value), `PartSpread` (`...v4`), `PartMethod` (`m(): v5`, a closure), `PartGetter`/`PartSetter` (`get a: v6`), `PartProto` (`[[Prototype]]: v7`, a non-computed `__proto__:` key, which sets the prototype; prototype-pollution rules match it). Object rest patterns are `object {...v1, -id, -secret}`: a spread with `PartExclude` keys. JSX props and enums are objects too. | Yes       |
| `array`  | `v10 = array [v1, <hole>, ...v2]`      | An array literal; a hole is `NoValue`; a spread element is a `spread` value (printed with `...`).                                                                                                                                                                                                                                                                                                                                                                                                  | Yes       |
| `spread` | `v12 = spread v1`                      | Iterates a value for a spread context: array literal and call spreads, array destructuring of anything but an array literal.                                                                                                                                                                                                                                                                                                                                                                       | Yes       |

## Functions

| Op        | Printed                                   | Meaning                                                                                                                                                                                                                                                                                                                                                                               | Can throw |
| --------- | ----------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `closure` | `v11 = closure f3 [v1, v2] ; outer.inner` | Creates the function value of `Aux.Func`. The arguments are the values for the function's `FreeVars`, in order: cells of captured variables, and `this`, `arguments` or `new.target` for arrows. Flags: `AuxClass` (a class's constructor), `AuxDerived` (with `extends`), `AuxGetter`, `AuxSetter`. Function declarations get their closure where their scope is entered (hoisting). | No        |
| `await`   | `v13 = await v1`                          | Suspends until a promise settles; the result is the fulfilled value (typed with the awaited type). A rejection throws, so `await` gets an exceptional edge inside `try`. Also used for `for await` elements and top-level `await`.                                                                                                                                                    | Yes       |
| `yield`   | `v14 = yield v1` / `yield* v1`            | Generator yield; the result is the value sent back by `next()`. `yield*` has `AuxDelegate`.                                                                                                                                                                                                                                                                                           | Yes       |

## Terminators

Each block ends in exactly one of these.

| Op            | Printed           | Meaning                                                                                                                                                                | Can throw |
| ------------- | ----------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| `jump`        | `jump b3`         | Unconditional.                                                                                                                                                         | No        |
| `branch`      | `branch v1 b2 b3` | To `Succs[0]` if the argument is truthy, else `Succs[1]`. Without an argument (`branch * b2 b3`) the iteration protocol decides: the head of a `for…of`/`for…in` loop. | No        |
| `return`      | `return v1`       | Returns its argument (`undefined` when none is written).                                                                                                               | No        |
| `throw`       | `throw v1`        | Throws; inside a `try` it has an exceptional edge to the handler.                                                                                                      | Yes       |
| `unreachable` | `unreachable`     | Control can't get here: an abstract method's body, a `finally.throw` block nothing throws into, a `break` with no target.                                              | No        |
