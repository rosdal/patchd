# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private vulnerability reporting:
<https://github.com/rosdal/patchd/security/advisories/new>

Do not open a public issue for a security problem. You will get an acknowledgement within a few days, and a fix or a plan before any public disclosure.

## Supported versions

Until 1.0, only the latest release receives security fixes.
